# HTMX SPA Demo

A simple **SPA-like demo** using **HTMX**, **Node.js**, and **view-transition API**, with smooth page transitions and active navigation highlighting. No frontend frameworks required.

## Features

- Load pages dynamically without full reloads using HTMX
- Update browser URL with history support
- Smooth fade + slide animations using view-transition API
- Active link highlighting in navigation
- Works with fallback animations for older browsers
